# QoE dataset outputs

This directory preserves the compact `metadata.csv` and `final_training_dataset*.csv` files used by the QoE/VMAF proxy workflow.

The 1,800 raw rendered PNG frames (approximately 7.16 GB in the source workspace) are intentionally excluded from Git and should be kept in a separate archival backup. They can also be regenerated with the Unity project and the data-collection scripts under `Assets/Scripts/`.
